局内手册

怎么玩

三步走

  1. 读证物：左侧（手机上是上方）每一张证物都能展开。里面写的是可核实的先后、相邻、间距或格位关系。
  2. 排格位：右侧（手机上是下方）每一格放一件东西。点击卡片选中，再点另一格即交换；也可以用「上移／下移」按钮。
  3. 提交复原：系统会逐条核对，只告诉你「哪些关系和不符」，不会替你排好。

键盘操作

按键作用
Tab / Shift+Tab在证物、格位、按钮之间移动焦点
Enter / Space展开证物、选中格位、触发按钮
↑ / ↓焦点在格位上时，直接上移／下移该物件
Esc取消当前选中

三档提示

每案都有三段提示：先给方法，再点出关键组合，最后给出较直接的推导。提示不会自动替你排列，也不会扣分或羞辱你。使用过提示只会在本地记录一个「用过提示」的标记。

你的进度存在哪里

进度只写在你当前浏览器的 localStorage 里，键名前缀 zd:v1:。不会上传、不会同步、没有账号。清除浏览器站点数据、或点击下方按钮，就会全部消失。

可访问性

  • 所有拖放操作都有等价的按钮操作，不依赖指针拖拽。
  • 交互目标按 44 px 设计；键盘焦点始终可见。
  • 解谜所需的区别都用文字与编号表达，不单靠颜色。
  • 尊重系统的「减少动态效果」设置，纸张动画会自动关闭。
  • 默认无声音；本版本不包含音频资源。

关于、隐私与许可

第零证物局

第零证物局是一个独立创作的微型互动谜题实验：把「记录如何构成事实、又怎样误导人」做成可以亲手排列的证物。

隐私

本作不需要创建账户，也不会把你的答案发送给任何在线 AI 或服务器。页面内的一切规则判定都在你的浏览器里完成。

如果你同意本机保存进度，记录只写在你当前浏览器的 localStorage 中，你可以随时清除。网站托管方（例如 GitHub Pages）仍可能按平台政策保留常规访问日志，这不在本项目的控制范围内。

本站不包含广告 SDK、跟踪脚本、第三方 CDN 或远程字体。页面加载时不发起任何第三方网络请求。

内容伦理

全部人物、地点、机构与事件均为虚构的架空世界「雾港」。本作不影射真实死者、真实机构或现存个人，也不以伪造的历史文书冒充真实档案。

许可

程序代码与叙事、插图等创作材料分别许可，具体条款见仓库中的 LICENSE 与 ASSETS_LICENSE.md。
