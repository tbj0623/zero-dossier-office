## 0. 全局语义约定（本项目合同）

| 中文表述 | 对应算子 | 严格含义 |
|---|---|---|
| 紧接在 X 之前 / 紧接着就是 X | `immediately_before` | 索引相邻且有方向 |
| 紧接在 X 之后 | `immediately_after` | 索引相邻且有方向 |
| 挨在一起 / 相邻格位 / 没有留下前后方向 | `adjacent` | 索引相邻，**无方向** |
| 格位编号相差 N | `distance, gap=N` | \|索引差\| == N，中间隔 N−1 件 |
| 在 X 与 Y 之间 | `between` | 严格区间，**不要求居中** |
| 早于 / 晚于 / 左 / 右 | `before` / `after` | 严格顺序，**不要求相邻** |
| 第 N 格 / 第 N 次 / 最右侧 / 最末 | `at` / `not_at` | 绝对格位 |
