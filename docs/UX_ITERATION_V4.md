# V4 · 在玩家需要时把证据带回来

## 决策记录

V3 的存档、撤销/重做、自动续玩已经解决中断后的恢复问题。
V4 不扩案，不增加积分、计时或推理助手，不猜测真人玩家喜好。
选择修复一个可从代码与布局直接证明的摩擦：

- 宽度 980px 及以下，证物册和复原板纵向排列；提交失败后需要穿越长页面，找到提示中的 E01 等证物
- 失败反馈虽指出冲突证据，但缺少可操作的「返回该证物」链接
- 点击第二个格位完成交换后，原 DOM 被替换，焦点可能丢失

参考：
- Nielsen Norman Group · *Onboarding Tutorials vs. Contextual Help*：帮助应贴近使用情境，避免强制提前教学
  https://www.nngroup.com/articles/onboarding-tutorials/
- WCAG 2.2 · 2.4.11 Focus Not Obscured：键盘焦点不能被作者界面完全遮挡
  https://www.w3.org/TR/WCAG22/#focus-not-obscured-minimum

## 已实现的变化

1. **纵向布局专属往返按钮**。证物册末尾可以「去复原格位」，复原板顶部可以「回看证物」。
   在桌面双栏模式隐藏，不额外占据空间；按钮不会修改 URL fragment 或触发路由重载。
2. **冲突证据直达**。提交后原有规则检查完全不变，冲突列表改成每张证物的可操作按钮。
   点击后会展开该证物、将 `aria-expanded` 更新为 true，并将焦点与滚动定位到证物标题；
   **不会直接揭示正确顺序**。
3. **交换后的键盘焦点**。选中第一格与目标格交换后，将焦点放回目标格的「选取/取消选取」按钮。
4. **对减少动态的尊重**。跳转使用原生 `scrollIntoView`，用户启用 reduced motion 时使用非动画行为。
5. **完整英文文案**。新增两个往返入口及冲突证据直达按钮，保持国际化 key 与中英文本一致。

## 质量门禁

- `tests/browser/ux_v4.py`：320/360/390/768/980px，证据与格位双向跳转、焦点、冲突证据展开、
  交换后焦点、页面无横向溢出及浏览器错误；1280px 关闭手机专用按钮；英文模式；
  Firefox 与 WebKit 复验关键焦点路径。
- GitHub CI 纳入 V4 浏览器测试，继续保留 V3 及原有中文、英文、三引擎、axe 无障碍测试。
- `site/i18n/en.json` 只增添新 key，不改变旧版文本或故事内容。
- 不更改六案的结构化规则、唯一解、案卷作者后记与提示级别。

## 接下来的待验证假设（不是已完成事项）

**G5 真人试玩仍为 0**。本次的优化是依据已确认的交互设计缺口，不是依据玩家研究数据。
下一步要让至少 3–5 位陌生玩家在手机上从零进入第一案，观察：

- 是否能自发找到复原板，是否还要频繁用手滚动来回找证物
- 提交错误后是否能明白「冲突证据」是回去复查，而不是答案
- 是否愿意完成第二案，以及中途退出后能否自然从首页续玩

只有形成重复证据后，再讨论双页签、可固定证据摘要、逻辑笔记本或新手演示。
不凭 Agent 自测的通过率宣布玩家已经满意。
