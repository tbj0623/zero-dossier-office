# 玩法说明 · GAMEPLAY

## 一句话

一件证物说真话不难，难的是六件证物同时说真话。你的工作是把互相错位的记录**排回它本来的秩序**，让"不可能"重新变得合理。

## 三分钟上手

### 1. 读证物

打开一份档案后，左栏（手机上是上方）是**已采集证物**。点标题即可展开正文。

每张证物都写明了一种**可核实的关系**，且只有这几种：

| 证物里可能出现的说法 | 它严格意味着 |
|---|---|
| "红票紧接在蓝票之前，中间没有其他票" | 两张**相邻**，且红在蓝**前一位** |
| "铜铃和值班簿挨在一起，没记下谁高谁低" | 两张**相邻**，但**不确定谁在前** |
| "绿票的登记晚于黄票" | 绿在黄**之后**，中间可以隔很多件 |
| "铜铃与旧透镜的格位编号相差三格" | 两者之间**隔着 2 件**（不是 3 件） |
| "旧透镜处在铜铃和海图之间，但不是等距" | 严格夹在中间，**不要求居中** |
| "最右侧的第四格一直装着玻璃球" | 它就在**第 4 格** |

> 💡 最容易搞错的是**「相差三格」**：它指格位编号之差是 3，所以中间隔 **2** 件物品。

### 2. 排格位

右栏（手机上是下方）是**复原格位**。有三种等价操作方式：

- **点击交换**：点一张卡片选中它，再点另一个格位，两者交换。
- **上下按钮**：每格右侧有 `↑` `↓`，一次移动一格。
- **拖放**（桌面宽屏）：直接拖动卡片到目标格位。

三种方式**效果完全相同**。不想用鼠标也没关系——见下面的键盘操作。

### 3. 提交与反馈

点「提交复原」。系统会**逐条核对**你的排列与证物里的关系：

- ❌ **不一致**：告诉你「有 N 条关系未满足」，并列出是哪几张证物的关系冲突，**但不会告诉你正确位置**。你的排列会完整保留。
- ✅ **全部满足**：归档成功，进入结案页。

## 键盘操作

| 按键 | 作用 |
|---|---|
| `Tab` / `Shift+Tab` | 在证物、格位、按钮之间移动焦点 |
| `Enter` / `Space` | 展开证物、选中格位、按下按钮 |
| `↑` / `↓` | 焦点在格位上时，直接上移 / 下移该物件 |
| `Esc` | 取消当前选中 |

从进入页面到完成归档，**全程不需要鼠标**。

## 三档提示

卡住了就点「查看提示」。每案有三档，逐级递进：

1. **方法**：告诉你先从哪儿下手（例如"先把玻璃球固定在最右边"）。
2. **关键组合**：指出哪两条关系必须一起用。
3. **较直接的推导**：说出一个中间结论。

提示**不会自动帮你排好**，也**不会扣分或羞辱你**。用没用过提示，只在本地记录一个标记。

## 进度与隐私

- 进度存在你浏览器本地（`localStorage`，键前缀 `zd:v1:`），刷新、关标签页再回来都不会丢。
- 想清空：**玩法说明页 → 清除本机全部进度**。
- **不上传任何东西**：没有账号、没有后端、没有跟踪脚本。详见 [PRIVACY.md](PRIVACY.md)。

## 六案与三幕

| 幕 | 档案 | 难度 | 机制焦点 |
|---|---|---|---|
| I · 错位的开端 | 001 末班车的四张车票 | 新手 | 紧邻 + 否定格位 |
| | 002 封存室的四格抽屉 | 进阶 | 绝对格位 + 定向相邻 |
| | 003 静默分拣线上的五个包裹 | 挑战 | 两条相邻链拼接 |
| II · 灯塔与回信 | 004 灯塔没有亮起的第五盏灯 | 进阶 | **无方向相邻** + 固定间距 + 夹在中间 |
| | 005 寄不到的第五封回信 | 进阶 | 夹在中间的逆向推理 |
| III · 第零张底片 | 006 第零号空白底片 | 挑战 | 六件综合 + 终章 |

六案之间有一条**隐形主线**：反复出现的半枚「0」章。它不是解谜所需的线索，漏看也不会卡关——但看完整季，你会明白它到底是什么。

## 结案页怎么读

结案页分成**两段**，请不要混淆：

1. **逻辑复盘**（严格可证明）：你的最终排列，以及每条证据如何锁死位置。表格里的"为什么必须"会告诉你：删掉这条关系，其余证据还允许几种排列。
2. **档案后记**（结案后补充记录）：故事层面的解释——误会怎么形成的、主角的心情。**它不构成刚才排序的证明**，只是叙事的余味。

这个区分是刻意的：我们不想用一段煽情的故事，冒充你刚刚完成的逻辑推理。

## 常见问题

**Q：这游戏需要联网吗？**
首次加载页面需要。加载完之后，判定完全在你的浏览器本地完成，不发任何请求。

**Q：我的答案会被上传吗？**
不会。没有后端，也没有在线 AI。你可以打开浏览器开发者工具的网络面板自己确认。

**Q：为什么提示这么含蓄？**
因为提示的目的是帮你继续，不是替你做。三档提示全部用完也解不出来，可以重置重来，或者去 [作者指南](AUTHOR_GUIDE.md) 看看这类谜题的通用思路。

**Q：可以自己写案件吗？**
可以。格式与公平性要求见 [AUTHOR_GUIDE.md](AUTHOR_GUIDE.md)。新案必须通过形式化、语义、盲审、浏览器四道门禁才会进档案柜。

**Q：为什么只有六案？**
因为每一案都经过四项独立审查。宁可少，不上一堆没验证的。后续季是否扩展，要看真实玩家反馈（见 `docs/PLAYTEST_PROTOCOL.md`）。
