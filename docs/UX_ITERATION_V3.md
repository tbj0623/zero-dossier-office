# 第零证物局 · V3 玩家体验升级记录

版本：2026-11-02（北京时间）
范围：游戏运行时、存档/撤销/续玩、双语动态反馈、浏览器回归、GitHub CI。
边界：不改六案形式化约束、正确解与结案故事；不伪造真人试玩数据；不新增追踪器或外部依赖。

## 判断逻辑：从自动化满分走向真人体验

V2 已经具备六案唯一解、三引擎浏览器测试和双语支持，但这些指标只说明「能运行」。
V3 选择优先修复玩家真实感受到的摩擦，保留以后开展陌生玩家试玩时可比较的基线。

### 这次已经实现

1. **可靠导航**：导航 epoch 隔离过期的异步案件加载；离开页面时取消延迟结案定时器；回放重新绑定事件监听，避免一次点击重复执行。
2. **可恢复的操作历史**：撤销、重做各有最多 50 步，排列、提示数、尝试次数和两个历史栈按案件存到本地。旧版只有排列/提示的存档仍兼容。
3. **无损错误恢复**：不合法的主排列被清除并使用安全初始排列；历史中无效条目被过滤；异常提示计数限定在 0～本案提示总数，尝试次数限定在安全范围。
4. **智能续玩**：首页优先指向最近更新的、未结案的有效存档；没有未完存档则指向第一份未归档案；档案柜区分「可调查／整理中／已归档」。
5. **键盘与触摸**：增加重做按钮，Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl/Cmd+Y 可操作；修复卡片交换成功后选中高亮未清除的问题。
6. **双语动态反馈**：补齐约束冲突、提交成功/失败、提示、移动/重做、续玩与卡片状态等运行时英语文案，避免英文模式只翻译静态页面。
7. **回归门禁**：新增纯函数验证与独立 Playwright 回归，结合已有 6 案、键盘、跨引擎、axe、ZIP 隔离和英文通关门禁。

### 主动不做的事

- **不加倒计时、排行榜或失误惩罚**：缺少真人反馈前，这些功能可能违背本作慢读证据的定位。
- **不为增加内容而盲目扩案**：现有六案的难度曲线与玩家理解成本尚未通过陌生人样本验证。
- **不引入账号/云同步/用户分析 SDK**：现阶段本地无账号是可感知的隐私价值。
- **不宣称某次 Agent 测试代表人类认可**：G5 仍是 NOT_DONE。

## 下一轮的产品实验（必须以真人样本驱动）

按实验优先级排序，以下都是待验证的设想，而非已实施功能。

| 优先级 | 假设 | 最小验证方法 | 成功/失败标准 |
|---|---|---|---|
| P0 | 新玩家看不懂「格位/间距/相邻」术语 | 3～5 名陌生玩家冷启动，记下实际误读句子 | 任意可复现的双重语义需修；2 人以上误读同一关系则改教学 |
| P0 | 第一案的开场叙事没有足够吸引力 | 观察首次进入到第一次证据展开和第一次提交 | ≥2 人在 3 分钟内放弃，重做开场与视觉层级 |
| P1 | 三档提示的第 3 档过于直白 | 让玩家使用提示后说明仍需自己推导什么 | ≥2 人称「基本给了答案」，重写该提示 |
| P1 | 结束第一案后继续游玩意愿不足 | 记录第一案结束后有无主动打开第二案 | 完成第一案者的续玩率 <50%，先改结案钩子和按钮位置 |
| P2 | 手机证物读读改改时上下滚动过多 | 360/390 宽手机上实际使用，记录来回滚动困惑 | 出现明确的跳转负担后再考虑折叠摘要或置顶便签 |
| P2 | 玩家希望有「我的推理笔记」 | 先给测试者纸笔，看是否自然记录排位 | 确有重复记录需求，才设计本地便签，不污染推理与隐私 |

## 验收协议

运行：

    python engine/verify_cases.py
    python -m unittest discover -s tests/logic -p 'test_*.py'
    node --test tests/logic/solver.test.mjs tests/logic/player_state.test.mjs
    python tests/logic/cross_check.py
    node tools/build.mjs
    python -m http.server 8140 --directory dist
    python tests/browser/e2e.py --base http://127.0.0.1:8140
    python tests/browser/ux_v3.py --base http://127.0.0.1:8140
    python tests/browser/e2e_en.py --base http://127.0.0.1:8140
    python tests/browser/a11y.py --base http://127.0.0.1:8140
    python tests/browser/cross_engine.py --base http://127.0.0.1:8140
    python tools/build_itch.py

**解释边界**：Playwright WebKit 不等于真实 Safari/iOS，axe 自动检测不能替代 NVDA/VoiceOver；这些仍为待办。正式公开部署以 GitHub Actions 与 Pages 的构建记录为准，不能只根据本地通过认定线上完成。
