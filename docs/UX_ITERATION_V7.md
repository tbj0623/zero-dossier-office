# V7 · 离线存档保险箱与第一案行动卡

## 产品方向
本轮不改变六案的逻辑、答案或故事内容，而是从「能通关」升级到「能长期保管游玩成果、能自主学会操作」。

### 功能一：离线存档保险箱
玩家在玩法说明页下载一个版本化 JSON 文件，其中包括六案归档进度、排列、撤销与重做栈、提示次数、玩家主观推理笔记、第一案指引进度。文件只在浏览器本地生成和读取，没有云账号、服务端和上传请求。

导入新备份会替换当前浏览器的六案进度，而不会自动合并。导入前会显示文件覆盖确认；取消导入不改变任何存档。保持语言偏好、首次说明偏好与其他本地应用数据。

- 文件头：format=zero-dossier-local-backup，version=1，exportedAt，cases
- 只接受六个已审案件，不接受额外字段和陌生版本
- 输入文件最大 256 KiB，JSON 结构与每案实际物件集合严格核对
- 旧版缺少笔记和行动卡存档时安全降级；错误笔记矩阵安全置空，错误主排列被拒绝
- 先备份所有受影响的原始本地值，写入失败时尽最大努力回滚。不能虚假保证浏览器配额/硬件故障时绝对原子恢复
- localStorage 不可写会明确提示，不伪造导出和导入成功
- 备份可能包含玩家自己填写的逻辑记录，用户应自行保管，不宜随意公开

### 功能二：第一案行动卡
仅在第一案未归档且未关闭引导时显示「查看证据 / 实际调整一个格位 / 提交一次证据核对」三步。三步只有真实交互发生才变成已完成，不依赖自动推断谜底。
行动入口会带玩家定位到相应的证据、复原板和提交按钮；不会阻止玩家自由操作，也可以永久跳过。进度随本案存档保留，重置第一案后可重走引导。

### 工程边界
- 不改现有求解器，核心验证仍基于原有九种约束运算符
- 无新第三方 SDK、无云端同步、无跟踪、无上传
- 中英双语，移动端无横向溢出；按钮、表格与通知遵循可访问性规则
- 不把 Agent 自测写成真人认可。G5 真实盲测仍为 NOT_DONE
- GitHub Pages 仅在完整 CI 通过后发布，itch.io 新 ZIP 仍需单独上传
