# 隐私说明 · PRIVACY

最后更新：2026-10-29

## 一句话

**不需要账户，不需要联网求解，不上传你的答案。** 进度只存在你自己的浏览器里。

## 1. 我们收集什么

**本项目自身不收集任何个人数据。**

- 没有注册、登录或用户档案。
- 没有后端服务器、没有数据库。
- 没有分析 SDK、跟踪像素、广告脚本。
- 没有第三方 CDN、远程字体或跨站请求。页面加载时的全部请求都指向本站自身。

## 2. 什么会留在你的设备上

游戏使用浏览器 `localStorage` 保存进度。键名统一带前缀 `zd:v1:`：

| 键 | 内容 |
|---|---|
| `zd:v1:progress` | 哪些档案已归档、是否用过提示、归档时间戳、完成次数 |
| `zd:v1:order:<案件ID>` | 该案当前的排列顺序与已揭开提示数 |

这些数据**只在你当前这个浏览器、这个设备上**，不会同步到任何地方。

### 清除方式

- 站点内：打开「玩法说明」页 → 点「清除本机全部进度」。
- 浏览器设置：清除该站点的站点数据 / Cookie 与网站数据。
- 无痕模式：关闭窗口即自动清除。

如果浏览器禁用了 `localStorage`（例如某些隐私模式），游戏仍可完整游玩，只是不会记住进度，并且会静默降级——不会报错、不会阻塞。

## 3. 托管方的日志

本站通常托管在 GitHub Pages 或 itch.io 等静态平台。平台自身可能按**其隐私政策**记录常规访问日志（如 IP、User-Agent、请求路径）。这部分不受本项目控制，也无法由本项目读取或导出。

## 4. 分享功能

本版本不调用系统分享 API，也不生成带玩家答案的分享链接。若将来加入分享，会明确标注分享内容，并**默认不包含你的排列答案**。

## 5. 儿童与敏感内容

本作是虚构的档案推理小品，不含血腥、暴力、性内容，也不涉及真实人物或真实事件。适合一般公众阅读。由于完全不收集数据，因此也不存在针对未成年人的数据收集问题。

## 6. 变更

隐私策略如有修改，会同步更新本文件的「最后更新」日期，并在提交信息中说明。

## 7. 联系

请在仓库 Issues 中提出（不要在其中粘贴任何个人敏感信息）。

## 语言切换（英文版）

站点新增了运行时语言切换（`?lang=en` 或导航栏的 `EN` 按钮）。这一节说明它对隐私的影响。

| 问题 | 答案 |
|---|---|
| 语言选择存在哪里？ | 只存在 `localStorage` 的一个键：`zd:v1:lang`，值为 `zh` 或 `en`。 |
| 会告诉服务器我选了哪种语言吗？ | **不会**。语言是纯前端切换，没有任何网络请求携带它。 |
| 加载英文包会产生额外请求吗？ | 会且仅会：一次对**同源** `./i18n/en.json` 的 `fetch`（76 KB），且**只在你切到英文时**发生。中文玩家永远不会下载它。 |
| 这个请求会发到第三方吗？ | 不会。同源，和加载案件 JSON 完全一样。 |
| 会记录我的 IP / 设备 / 语言偏好到服务器吗？ | 本作没有服务器端逻辑，没有账号，没有分析脚本。托管方（GitHub Pages）可能按平台政策保留常规访问日志，这不在本项目的控制范围内 —— 与切换语言无关，访问任何页面都一样。 |
| 换回中文会怎样？ | `zd:v1:lang` 被改为 `zh`，不再请求 `en.json`。清除站点数据可彻底删除该键。 |

英文翻译同样**不改变游戏逻辑**：求解器内部始终使用中文规范 ID，
语言只影响"显示给人看的字符串"。因此切换语言不会影响存档、判题或任何进度数据。
