## 1. 为什么这一步不能由 Agent 代做

Agent 之间互相夸奖不是市场调查。本项目的形式化校验、语义审稿、独立盲审能发现**逻辑与文本缺陷**，
但**无法证明**：

- 人类玩家觉得这个谜题好玩 / 难度合适；
- 手机上真的读得下去；
- 提示梯度在真实卡壳时是否有用；
- 玩家是否愿意玩第二案。

这些只能由真人给出。

## 3. 试玩协议（给代为执行的人）

### 3.1 招募

- 找 **3–5 名没见过本项目**的成年人。
- **必须事先告知并取得同意**：会记录「完成情况 / 是否用了提示 / 用时 / 主观一句话」，不记录任何个人身份信息。
- 不能找已经读过案件 JSON 或本仓库的人——那不算盲测。

### 3.2 操作

1. 只给链接，**不要口头解释规则**。
2. 不提示答案，不指出"你应该点这里"。
3. 观察并记录（不打断）：
   - 第一次成功提交前，是否理解了「先后 / 相邻 / 间距 / 夹在中间」的区别；
   - 卡住时**先看证据**还是**先点提示**；
   - 有没有把 `distance` 的"相差三格"理解成"中间隔三件"；
   - 手机上是否有需要缩放才能读的内容；
   - 完成第一案后，**是否主动点"继续下一案"**。
4. 结束后问三个问题即可，不要引导：
   - 哪里最让你困惑？
   - 有没有哪句话你觉得可以有两种读法？
   - 还想玩下一案吗？为什么？

**不填真实姓名**，只用 P1、P2 这样的代号。

**发送时的三条纪律**（对应 §3.2）：

1. **只给链接**，不要附截图、不要附玩法说明、不要口头讲规则。
2. **不要在现场提示**。对方卡住时可以说"游戏里有提示按钮"，除此之外不开口。
3. **不要问引导性问题**（"是不是很好玩？"）。只问 §3.2 那三个开放问题。

#### 回收后如何判定

**先看样本量，再看内容。** 判定口径固定，不靠感觉：

| 门槛 | 结论口径 |
|---|---|
| **n = 0** | 状态维持 `NOT_DONE`。对外**不得**出现"玩家反馈""试玩好评"任何字样。 |
| **1 ≤ n < 3** | 只能写「初步观察（n=N）」，**不得**写成"玩家普遍认为"。结论只作参考，不改设计。 |
| **n ≥ 3** | 才允许按 §4 的规则触发设计修改；对外只能说"已有 N 名真实玩家试玩"。 |

**逐项判定**（与 §4 决策规则一一对应）：

| 观察 | 判定 |
|---|---|
| 第 2 题：同一关系被 **≥2 人**独立点名"分不清" | 触发 §4 第 1 行 → 全案改写措辞 + 玩法说明加图示 |
| 第 4 题：**任意 1 人**给出可复现的第二种读法，且能推出**不同**的唯一解 | **阻塞级**。进语义审稿队列，修复后重跑 `verify_cases.py` 与全部校验 |
| 第 4 题：有人指出两种读法，但两种读法得到**同一个解** | 记为"表述可优化"，不阻塞，进下一版文案队列 |
| 第 5 题：**≥2 人**说"基本等于给答案" | 触发 §4 第 3 行 → 重写第三档提示 |
| 第 7 题：完成第一案的人里 **<50%** 点"继续下一案" | 触发 §4 第 5 行 → 检查第一案结尾钩子与按钮位置 |
| 第 8 题：**任意 1 人**报告需缩放或出现横向滚动 | **阻塞发布**，先修布局（§4 第 6 行） |
| 第 1 / 6 / 9 题 | 描述性数据，只统计、不单独触发修改 |
| 第 10 题（评价意愿） | **仅作参考**。不得据此对外承诺"玩家愿意推荐"，也不得代替真实商店评价 |

**记录纪律**：

- 只保存**代号 + 答案**，不保存姓名、联系方式、IP、截图中的个人信息。
- 原始表单回收后，把结论填进 §3.3 记录表与 §6 模板；原始问卷可销毁。
- 只有 1 人提及、且不构成上表阻塞项的，记为「单点观察」，**不改设计**，进观察清单等下一轮。
- 任何一条结论都要能指回具体代号（P1/P2…），不能写"有人说"。

## 4. 决策规则

试玩结束后按以下规则决定下一版，**不靠感觉**：

| 观察到的现象 | 处置 |
|---|---|
| ≥2 人把 `distance` 读成"中间隔 N 件" | 全案改写措辞，并在玩法说明加图示 |
| ≥2 人在第一案 3 分钟内放弃 | 重做第一案的开场，不是加更多案件 |
| 有人说"提示直接给了答案" | 重写第三档提示 |
| 完成第一案的人里 <50% 点下一案 | 检查第一案结尾的钩子与"继续下一案"按钮位置 |
| 手机上出现横向滚动或需缩放 | 阻塞发布，先修布局 |
| 有人指出某条证据有两种读法 | 进语义审稿队列，修复后重跑全部校验 |
